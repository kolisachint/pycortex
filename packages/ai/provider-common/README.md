# cortexcode-ai-provider-common

Common AI provider utilities.

## Overview

This package provides shared utilities for AI providers, including:

- Cache retention helpers
- Simple options transformation
- Message transformation utilities
- GitHub Copilot header handling

## Installation

```bash
pip install cortexcode-ai-provider-common
```

## Usage

```python
from cortex.ai.providers._common import (
    transform_messages,
    handle_cache_retention,
)
```
