# cortexcode-ai-stream

AI streaming for the pycortex AI module.

## Overview

This package provides streaming support for AI responses, including:

- Stream processing and buffering
- Event handling and transformation
- Simple stream interface for basic use cases

## Installation

```bash
pip install cortexcode-ai-stream
```

## Usage

```python
from cortex.ai.stream import (
    stream_completion,
    SimpleStream,
)
```
