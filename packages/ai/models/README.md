# cortexcode-ai-models

AI models and registry for the pycortex AI module.

## Overview

This package provides:

- Model definitions and configuration
- API provider registry
- Built-in provider registration (lazy loading)
- Model cost and capability information

## Installation

```bash
pip install cortexcode-ai-models
```

## Usage

```python
from cortex.ai.models import (
    Model,
    get_api_provider,
    register_api_provider,
)
```
