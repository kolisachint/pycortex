# cortexcode-ai-util

AI utility functions for the pycortex AI module.

## Overview

This package provides utility functions including:

- JSON repair and validation
- Text overflow handling
- Diagnostics and error reporting
- Hashing utilities
- Header manipulation

## Installation

```bash
pip install cortexcode-ai-util
```

## Usage

```python
from cortex.ai.util import (
    repair_json,
    validate_json,
    overflow_text,
)
```
